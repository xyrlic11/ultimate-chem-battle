## Shared prompt

Mini pixel-art chemical game creatures, approximately 16–20 logical pixels,
hard square clusters, dark outline, one two-dot face, 5–6 palette colors,
one lower-right shadow plane, one small upper-left highlight. Flat navy
comparison sheet, formula captions, restrained charm. Distinct compact
silhouettes; no animal mascots, clothing, equipment, textures, noise,
dithering, gradients or elaborate facets. Preserve simple shapes when shading.
