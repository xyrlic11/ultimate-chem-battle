## Shared art direction

Polished hand-painted 2D fantasy game environments with readable silhouettes,
slightly stylised premium indie-game rendering, layered depth, edge framing and
a calmer central 55% for Thai UI and gameplay pieces. Palette progresses from
hopeful teal/blue through desaturated ruin tones and volcanic orange to astral
violet/gold. Every prompt prohibited text, logos, watermarks, HUD, borders,
modern objects and centre-heavy visual clutter.
