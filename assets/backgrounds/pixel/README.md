# Pixel-art migration assets

Generated with the built-in OpenAI image generation tool on 2026-09-08.

- `prep_01_capital_market.png`: safe opening preparation hub, fantasy capital
  alchemy district, warm daytime shopping mood and calm central plaza.
- `prep_02_expedition_camp.png`: mobile alchemist camp after leaving the city,
  used for later preparation and rest events during the first migration pass.

Shared prompt direction: wide 16:9 polished 2D pixel-art environment,
consistent visible square pixels, crisp hard edges, 16/32-bit fantasy RPG
language, rich limited palette, calm central 60% for Thai UI, no readable text,
logos, HUD, modern objects, anti-aliasing, painterly rendering or 3D.

These are the first assets in a gradual whole-game pixel conversion. Painted
battle backgrounds remain intentionally active until their pixel replacements
are ready.
